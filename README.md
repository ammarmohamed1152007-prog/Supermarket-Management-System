Supermarket Management System

A Python-based supermarket management system developed using
Object-Oriented Programming (OOP).

Features:
- Admin management
- Employee management
- Customer management
- Product management
- Inventory management
- Shopping cart
- Order processing
- Payment processing
- Receipt generation

Technologies:
- Python
- Object-Oriented Programming
- Mermaid
